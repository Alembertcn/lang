长难句精讲
主干定位从句分析
生成AIをめぐっては旧フェイスブックのメタが先月、最新の技術を発表したほか、グーグルも今月14日に開発者会議を開いて最新製品を公開するとみられ、IT各社による開発競争が激しくなっています。
【主干定位】

主干定位

1.全句-文末找谓语，定主句

锁定句尾谓语：激しくなっています

确认句型结构：○○が激しくなっている

寻找主语/主题标志助词“が”：【IT各社による開発競争が】

生成AIをめぐって：提示话题的范围

框定主句范围：生成AIをめぐって、IT各社による開発競争が激しくなっています。


2.主句-去枝叶，抓主干

主要信息

由于“IT各社による：”限定了【開発競争】的主体，是不可或缺的重要信息，意义上可保留


次要信息

生成AIをめぐって：提示话题范围作用，在判断主干时可忽略

得出主干：IT各社による開発競争が激しくなっています。

生成AIをめぐっては旧フェイスブックのメタが先月、最新の技術を発表したほか、グーグルも今月14日に開発者会議を開いて最新製品を公開するとみられ、IT各社による開発競争が激しくなっています。
【从句分析】

1.【~を発表したほか】

生成AIをめぐって：围绕/针对某种事物、话题等展开。在表达话题的同时，也隐含了“该话题的不同立场或主体”，从而形成对比的含义。


如：この問題をめぐっては、賛成意見もあれば反対意見もある。（关于这个问题，有赞成意见，也有反对意见。）


2.【~を公開するとみられ】

①を開いて：在该语境下表达顺接，内含因果递进关系。【開発者会議】在先，【最新製品を公開するとみられ】为后续动作。


②~とみられる：“推测……”，以观察到的事情、事实为基础去推测，用被动表客观，属于外部观察结论，非主语主动行为
