主体概要：

主句分析：

1.氷には：【は】 提示句子主题（话题）是“冰块”，【に】表示存在的位置，整体意为“在冰块中”。

2.果物が入っているものもあり：【果物が】是小主语，【入っている】是动词持续体作定语修饰【もの】，【ものもあり】是【ものがある】的句型，表示“也有……的东西/情况”，中顿连接后文。

氷には、動物たちの好物の果物が入っているものもあり、ツキノワグマのものにはキウイフルーツが、ゾウのものには、グレープフルーツやオレンジといった数種類の果物が入っています。
【从句分析】

分句拆分：

1.ツキノワグマのものには/キウイフルーツが/、/ゾウのものには/、/グレープフルーツやオレンジといった/数種類の果物が/入っています。

① ツキノワグマのものには：【の】 表示所属，“黑熊的”；【もの】指代“冰块”；【には】表示存在的场所。

② キウイフルーツが：【が】 提示存在的主体。

③ ゾウのものには： 同上。

④ グレープフルーツやオレンジといった：【や】 表示列举；“～といった”用于举例，意为“像……之类的”。

⑤ 数種類の果物が： 存在的主体。

⑥ 入っています： 谓语。


重点语法详解：

【～といった】

释义： 用于列举代表性的事物，暗示还有其他同类。“……之类的”、“……等等”。

接续：

名词 + や + 名词 + といった + 名词

名词 + といった + 名词

常见用法：

用于举例说明，比单纯的「や」更具概括性和强调“之类”的意味。

常与「や」连用，构成「～や～といった」的列举结构。

例句：

東京や大阪といった大都市には、人が多く集まる。（在东京、大阪等大城市，人聚集很多。）

【～がある／がいる】的存在句及省略

释义： 表示“有……”。

接续：

场所 + に + 物/人 + が + ある/いる

常见用法：

本句是典型的存在句结构，但后半部分因前后对仗，将谓语【入っています】统一放在句末，前半部分的【が】后省略了谓语。

例句：

机の上に本がある。（桌子上有书。）
