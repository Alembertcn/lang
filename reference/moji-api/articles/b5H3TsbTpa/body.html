【语法精讲1】

这些敬语是什么意思？

1.ご案内いたします

①案内する：サ变动词，意思是“引导、带路、介绍”。

②ご + 案内：【案内】是汉语词汇，所以用【ご】构成 敬语形式的名词化。

③いたします：【する】的 自谦语，用于说话人自谦、降低自己行为。【します】更礼貌形式。

常用于服务业/接待/商务场合/说明


2.こちらへ　どうぞ

①こちら：指示词，表示“这边/这里”，是【ここ/これ】的更礼貌说法。

②どうぞ：副词，用于请对方做某事，含有“请、请便、请随意”的礼貌邀请。

省略了后半句的动作。例如【お進みください（请移步）】【お座りください（请坐）】等


③こちらが　メニューで　ございます

①が：主语提示助词。

②メニュー：外来语，菜单。

③でございます：【です】的敬语。比【です】的更礼貌、更正式的表达。

【こちらが　〇〇でございます 】是【これは〇〇です】更尊敬的表达方式，常用于需要向对方表示尊敬的场合。


④ご注文は　いかが　なさいますか。

①ご注文：与【ご案内】一样，是サ变动词的敬语形式名词化

②いかが：【どう】的郑重表达。表示“怎么样”“如何”，用于敬语场合。

③なさいます：【なさる】是【する】【なす】的敬语形式

【いかがなさいますか】常用于询问对方意见时使用

句式表达

小贴士

1.基本上，和语词前加【お】、汉语词前加【ご】。

2.【ます形】前+【お/ご】，此时整体作为一个名词或サ变动词使用。

变成名词：

待つ→お待ち→お待ちください（请稍等一下）

变成サ变动词：

説明→お説明する

【〇〇にします】：我决定要这个！

句式表达

〇〇にします


句式讲解

1.〇〇：名词

2.にする： 做出选择 → “决定要～/选择～”

常用于点餐、买东西、日常选择。


例句

1.カレーに　します。（我决定吃咖喱饭。）

2.髪型は　短めに　します。（发型我决定剪短点。）


小贴士

结账时可用【お会計をお願いします/すみません、お会計】

【语法精讲2】

【〇〇をください】：请给我这个！

句式表达

〇〇をください


句式讲解

1.〇〇を：名词+を

2.ください：“请求对方做某事”，但通常不能对尊长说，因为这带有命令语气


*在更礼貌的场合会说【～をお願いします（拜托了）】、【～をいただけますか（可以~吗）】。

**【ください】需要接续动词て形如：助ける→助けてください（请帮帮我）

***【つ】通常用来计个数或件数使用

如【一つ】【二つ】（一个、两个）。


例句

コーヒーを　ください。（请给我咖啡。）

東京までのきっぷを　ください。（请给我一张到东京的车票。）
