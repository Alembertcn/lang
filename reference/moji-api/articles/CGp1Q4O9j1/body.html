すみません、私は　財布を　落としてしまった　みたいですが、ここに　届いていませんか。
【语法精讲1】

句式表达

动词て形 + しまう (……完了；……了 / 不小心……了)


句式讲解

1.完成、结束：表示动作的彻底完成或结束，常带有“完全做好、用完、结束”的语感。

例：この本を読んでしまいました。（我把这本书读完了。）

2.遗憾、意外：表示发生了说话人原本不希望发生或意料之外的事情，带有后悔、惋惜、惊讶或感到麻烦的语气。

例：約束を忘れてしまいました。（我不小心把约会给忘了。）

すみません、私は　財布を　落としてしまった　みたいですが、ここに　届いていませんか。
【语法精讲2】

句式表达

口语化形式：在口语中经常约音为 「ちゃう」（てしまう） 和 「じゃう」（でしまう）。

食べてしまう → 食べちゃう

飲んでしまう → 飲んじゃう


1.意志动词 + てしまう：通常表示“完成”，有时在特定语境下也可表示“遗憾”。

例：ケーキを一人で食べてしまった。（我竟然一个人吃光了蛋糕。）【完成 / 略带后悔】

2.非意志动词 / 自动词 + てしまう：通常表示“遗憾、意外”。

例1：電車が行ってしまった。（电车开走了。）→意外

例2：病気になってしまった。（生病了。）→遗憾

昨日の　夜です。確か、公園を　散歩している時は　まだあった　気が　しますが、バス停に　着いたら　なくなったことに　気づきました。
【语法精讲1】

句式表达

句子（普通形）+ 気がする (我觉得好像……；我感觉……)


句式讲解

用于委婉地表达说话人基于感觉、印象或直觉的想法。

比【思います】的主观确信度低得多，更接近于“隐约觉得”、“好像”。


例句

1.どこかで彼に会ったような気がします。（我总觉得好像在哪见过他。）

2.彼の話は少し嘘っぽい気がする。（我觉得他的话有点假。）


【気がする vs 思う vs 感じる】

1.【気がする】：模糊的直觉或印象。说不出具体理由，“就是有这种感觉”。

例：今日は何かいいことがありそうな気がする。（我感觉今天好像会有好事发生。）

2.【思う】：基于一定思考或信息的想法、意见。确信度更高。

例：彼の意見は正しいと思う。（我认为他的意见是正确的。）

3.【感じる】：直接的感官感受或内心感动。

例 寒さを感じる。（感到寒冷。）

昨日の　夜です。確か、公園を　散歩している時は　まだあった　気が　しますが、バス停に　着いたら　なくなったことに　気づきました。
【语法精讲2】

句式表达

名词+に気づく (察觉到……；注意到……)


句式讲解

【に】：表示注意到的对象或内容。当对象是句子时，需要将句子名词化。


例句

1.彼がずっと黙っていることに気づきました。(我注意到他一直沉默不语。)

2.後ろから誰かがついてくるのに気づいた。(我察觉到有人从后面跟了上来。)


【～に気づく vs ～を見つける】

1.~に気づく：被动地、自然地察觉。对象可以是抽象事物（变化、事实）或具体事物。

例：色の　変化に　気づきました。（注意到颜色的变化。）

2.～を見つける：主动地、有意识地寻找并发现。对象通常是具体事物。

例：地図で　その店を　見つけた。（我在地图上找到了那家店。）


拓展

〇〇（句子普通形）だと気づきました。也是同一个意思！

例：それは　間違いだと　気づきました。（注意到那是错的。）

【语法精讲1】

句式表达

名词A + くらいの + 名词B + さです (有像A那样的B的程度；相当于A的B)


句式讲解

通过用常见事物A来比喻，说明抽象事物B达到了何种程度。

1.名词A + くらいの：【くらい（ぐらい）】表示程度，“像……那样的程度”。这里用具体事物A来设定一个程度的基准。


2.名词B + さ：【さ】是接尾词，接在形容词/形容动词词干后，将其名词化，表示“程度”。

例：大きい → 大きさ（大小）、深い → 深さ（深度）、静かだ → 静かさ（安静的程度）


例句

1.リンゴくらいの大きさです。（有苹果那么大。）

2.針が落ちる音も聞こえるくらいの静かさだった。（安静得能听到针落地的声音。）


拓展

ぐらい/くらい意思和用法完全相同，可以互换。

在日常口语中，常省略【の】和【さ】，直接用【名词A + くらい + 形容词】」。


例句

1.リンゴくらい大きい。（像苹果那么大。）

2.針が落ちる音が聞こえるくらい静かだ。（安静得能听到针落地的声音。）

5000円くらいの　現金と　クレジットカード2枚と　私の　IDカードです。

①い形容词去【い】+【さ】

②な形容词+【さ】


部分形容词+さ变成名词，表示性质与状态的程度。

如：暑さ（炎热程度）、大きさ（大小）、長さ（长度）、静かさ（安静程度）

【ところで】用在转换话题时，表示“对了”、“话说回来”，用于引出与当前内容不直接相关的新话题。
