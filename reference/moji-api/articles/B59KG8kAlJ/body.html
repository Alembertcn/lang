【语法精讲1】

如何表达不确定的推测

句式表达

〇〇（动词普通形）かもしれない


句式讲解

1.虽然是【ません】但并不表示否定！

2.用于表达不确定的推测，表示“也许……”、“可能……”，带有说话人主观的“可能性”判断。在口语中可简化为【かも】。


例句

この　食べ物は　辛い　かもしれません。（这个食物也许是辣的。）

この　食べ物は　彼が　食べた　かもしれません。（这个食物可能是他吃的。）

頭が　痛くて、風邪を　ひいた　かもしれません。……それは　大変ですね。病院に　行った方が　いいですよ。
【语法精讲2】

如何建议别人做某事？

句型表达

〇〇（动词た・ない形）+ほうがいい


句式讲解

1.动词词た形 + ほうがいい → “最好……（去做某事）”

2.动词ない形 + ほうがいい → “最好不要……（不做某事比较好）”

3.用于提出 建议/忠告/提醒


例句

1.これを　食べない　方が　いいです。（不要吃这个比较好。）

2.熱が　ひどいから、病院に　行った方が　いいですよ。（你发热这么厉害，去医院看看吧。）

【语法精讲1】

“即将……”“打算……”

句式表达

〇〇（动词原形）+ところ


句式讲解

1.表达动作即将发生的阶段：动词原形+ところ

2.表达动作正在发生的阶段：动词ている+ところ

3.表达动作刚刚完成的阶段：动词た形+ところ


例句

これから　ご飯を　食べる　ところです。（接下来打算去吃饭。）

そうですね、私も　そう思って、今病院に　行くところです。……今日は　お休みだと　先生に　伝えますから、お大事に。
【语法精讲2】

转达的日语要怎么说？

句式表达1

名词/形容动词+だ+と〇〇に伝える

动词原形/形容词+と〇〇に伝える


句式讲解1

1.【と】表示引用（传达/转述别人的话）

2.动词原形/形容词直接+【と〇〇に伝える】

3.名词/形容动词+【だと〇〇に伝える】


例句

1.彼は　学生だ　と　先生に　伝えました。（我把“他是学生”转告给了老师。）

2.行く　と　彼に　伝えました。（ 转告他说“要去”）

句式拓展

转述“谁说了什么”的关键句型


句式表达2

1.直接引用：〇〇は「」という/と話す

2.间接引用：〇〇は〇〇という/と話す


句式讲解2

1.直接引用时「」内为完整的他人所说的话，相当于中文的双引号

2.间接引用，【と】前若为名词/形容动词则需要+【だ】


例句

1.田中さんは「行きます」と言いました。（田中先生说“要去”→直接引用）

2. 山田さんは来週日本へ行くと話しました。（山田先生说下周要去日本→间接引用）


注意

1.【〜っていう / 〜っていってた】是其口语形式

例句：田中さんが来ないって言ってたよ。（田中说他不来哦。）


2.【〜とおっしゃる】尊敬语

例句：社長は午後から会議だとおっしゃいました。（社长说下午有会议。）


3.【〜と申す／申します】自谦语

例句：私は李と申します。（我叫李。）
