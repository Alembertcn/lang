【～てもらおうと】

释义： 表示为了实现请对方（或让某物）做某事的意图而采取后项行动。“为了请……做……”，“为了让……”。

接续：

常见用法：

用于表达说话人出于使对方受益或为自己做某事的意图而进行后项动作。

例句：
