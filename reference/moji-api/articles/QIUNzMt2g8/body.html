　通常、ロボットに対するプログラミングは、センサから取得した情報に応じてロボットが何らかの反応をするようなものを作っていく。たとえば「障害物を察知したら避ける」といった具合のものである。しかし、僕はロボピーがもっと適当に、意味のない動きも含めてさまざまな行動を取るようにしたのだ。 300以上の動作プログラムをし、動作パターンが次々にどういう順番で発見するかというルールを700以上プログラムした。その結果複雑に、多様に動くロボットが実現された。ここまでやると、自分たちでもプログラムがどう作用するかわからなくなる。何に反応して、どんな行動をするか予測不能になった。

试读结束仅对[全文付费]类型文章生效


　　通常给机器人编写的程序，都是让机器人根据传感器传来的信息做出一些反应。比如“感知到障碍物就避开它”这种具体的程序。然而我还打算让机器人“robopi”做出各种各样的动作，包括能更随意地做出无意义的行动。我们编写了300多种动作程序，还编写了700种以上的规则，规定以何种顺序接连不断地发现动作模式。结果我们开发出了能做出复杂、多种动作的机器人。到这一步后，连我们也不知道这些程序是怎么运作的了。我们已经无法预测机器人会对什么有反应以及会采取什么行动。

　僕らがミーティングをしているとき、突然ロボピーは僕らの音声を認識し、「そうではないよ」と言って手をぶらぶらさせながらどこかへ向かって歩きだしたのだ。それを見て僕らは呆気にとられながらも、ロボピーに意思を感じてしまった。僕らの話を聞いていて、彼は思うところがあり、だからどこかへ行ってしまったのだろう、と。 

　　有一次我们在开会的时候，突然robopi识别到了我们的声音，说了一句“不是那样的哦”，然后晃着手开始朝着某个方向走去。看到这一幕，我们都感到无比震惊，但还是理解到了它的意思。也许是因为他听到我们说的话后，想到了什么，所以走向了某个地方。

　もちろんそれは、ロボピーの中のあるプログラムが、何かをきっかけに作動しただけのことだ。だがなにか首尾一貫したひとつの意思決定機構から生み出された行動であるかのように見えたのだ。

　　当然，这只是因为robopi中的某个程序，因为某个契机而运作了起来。但这看起来就像是一个条理清晰的大脑决策组织发出的行动指令一样。

　　那时我便确信，所谓的心，其实是观察一方的问题。

　非常に単純な機械の動きに「心を感じますか」と問えば、感じると言う人は少ない。多少複雑でも、原理を知っていれば「それは心ではない」と言う。しかし、人間は複雑である。いや、虫程度でもいい。動きが相当以上に複雑なものに対しては、相手のことを一から、すべては理解しきれない。自分の頭の中で完全に再現しきれない、解釈しきれない、理解しきれないほど複雑なもの、仕組みがよくわからないくらい入りくんだものが目の前にあると、「こいつは、私の知らないところで勝手に独立して考え、動いているのだろう」という想像が働く。その浮かんできた想像に名前をつけずにはいられなくなる。それを「心」と呼んでいるのだ。

　　如果要问“从机械非常单纯的动作里能感受到心的存在吗”，回答能感受到的人会很少。即便动作有些复杂，只要知道了原理，就不会认为那是心。然而，人类是很复杂的存在。应该说，即使是很小的动作，都是极为复杂的。我们没有办法从头开始完全理解另一个人。如果眼前出现了一些错综复杂的事物，无法在自己的头脑中完全再现、解释、理解，也不清楚其机制的话，我们就会产生想象，觉得这家伙是不是在我们不知道的时候开始自己独立思考、行动了。我不禁想给这种浮现出来的想象命个名，就叫做“心”。
[ 点击显示译文 ]


　心とは、複雑に動くモノに現実的にあるというより、その動きを経ている響が想像しているものなのだ。そしてその心は、見ている側の自分にもないと都合が悪い。とくに人間同士であればお互いに「心がある」と感じてしまっている。だからひとはみな「自分には心がある」とおもう。しかし心は、実は自分の中にいくら問い合わせ、内緒してみてもしょうがない。相手を観察し、想像することでしかわからないものなのだ。

　　与其说心存在于复杂的行动中，不如说它是从行动中产生的想像的产物。而如果观察的一方也没有这颗心，就无法体会到它的存在。人与人之间尤其能互相感受到心的存在，所以大家都会认为自己有心。但其实，心这个东西，自己再怎么与之秘密交谈也是感知不到的。只有在观察对方、展开想象的时候才能够感受到它的存在。

//練習

1.ロボピーが、ほかのロボットと異なる点は何か。
投票选项（最多1个）
1. 動作パターンがけられているので、ある程度動きが予測できる。
2. 与えられた情報の一身を自分で判断して動くので、動きが予測できない。
3. どう動くかというプログラムを多数組み込んだので。動きが予測できない。
4. 多様で複雑な動作をプログラムしたので、人間のように自然な動きができる。
正解：3 訳文： 1.有安装动作模式，所以一定程度可以预测的动向。 2.因为可以自己判断给出的信息而运行，不能预测动向。 3.因为组装了很多运行程序，所以不能预测的动向。 4.因为安装多样复杂的动作程序，所以可以像人一样自然活动。 解説： 机器人和其他的机器人相比不同点是什么。 1、有安装动作模式，所以一定程度可以预测的动向。 2、因为可以自己判断给出的信息而运行，不能预测动向。 3、因为组装了很多运行程序，所以不能预测的动向。 4、因为安装多样复杂的动作程序，所以可以像人一样自然活动。

2.どこかへ向かって歩きだしたとあるが、その時筆者にはどのように想えたか。
投票选项（最多1个）
1. プログラムに間違いがあり、ロボピーに意思が生まれて動いた。
2. プログラムが作動したのではなく、ロボピー自身が考えて動いた。
3. プログラムが作動して、意思があるかのようにロボピーが動いた。
4. プログラムが誤作動して、制作者の意図に反してロボピーが動いた。
正解：3 訳文： 1.程序错误，机器人产生理解力运行。 2.程序没有启动，是机器人自己思考运行的。 3.程序启动，如同有理解力一般，机器人运行了。 4.程序误启动，违反研发人的意图，机器人自己运行。 解説： 文章提到去往某个地方，那时作者是如何思考的？ 1、程序错误，机器人产生理解力运行。 2、程序没有启动，是机器人自己思考运行的。 3、程序启动，如同有理解力一般，机器人运行了。 4、程序误启动，违反研发人的意图，机器人自己运行。

3.「心」について、筆者はどのように考えているか。
投票选项（最多1个）
1. あると思って観察すれば、複雑な動きの意図が理解できる。
2. 実体がないので、あるとかないとか想像しても意味がない。
3. 仕組みが複雑すぎるため、人間同士であっても想像できない。
4. 理解しきれない複雑な動きを見たときに、人間が想像するものだ。
正解：4 訳文： 1.认为有然后观察的话，可以理解复杂的动向。 2.因为没有实物，想象有没有，没有意义。 3.因为结构过于复杂，所以即使是人类也不能想象。 4.当看到无法理解的复杂动向时，人类可以想象的东西。 解説： 关于心作者是如何思考的？ 1、认为有然后观察的话，可以理解复杂的动向。 2、因为没有实物，想象有没有，没有意义。 3、因为结构过于复杂，所以即使是人类也不能想象。 4、当看到无法理解的复杂动向时，人类可以想象的东西。

2.〜てしかたがない・〜てしょうがない・〜てたまらない

接続

动词て形・イ形くて・ナ形‐で＋しかたがない・しょうがない・たまらない

意味

前接表示说话人的感情、欲望等的词语。特别是「～てたまらない」多用于表达身体的感受。第三人称做主语时，要如例句④那样后续「ようだ・らしい」等。
