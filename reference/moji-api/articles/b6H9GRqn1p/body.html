什么？形容词还分两种？①——い形容词（又称“形容词”）


接续规则

1.“い形容词”以“い”结尾，名词咱直接接！

例：これは　美味しい料理です。（这是很美味的料理）


2.“い形容词”的否定：い→くない

例：この店の料理は　美味しくないです。（这家店的料理不好吃）

什么？形容词还分两种？②——な形容词（又称“形容动词”）


接续规则

1.“な形容词”接名词，中间得夹个“な”

【语法精讲1】

这个句式可以拿来用作对比！

句式表达

〇〇（名词1）は〇〇（形容词）が、〇〇（名词2）は……|


句式讲解

1.这仍然是简单判断句【〇〇は〇〇です】的扩写

2.【が】在这里表示转折，即“但是……”


例句

1.アニメは　好きですが、マンガは　好きではありません。（我喜欢看动漫，不喜欢看漫画。）

2.母は　優しいですが、父は　優しくないです。（妈妈很温柔，父亲不温柔。）


小贴士

が放在句尾时，可以表示转折也可以顺接，具体含义需要根据上下文判断。

①转折：表示前后内容的对比或转折。例：天気がいいですが、風が強いです。（天气很好，但风很大。）

②顺接：表示前后内容的顺接或补充。例：日本語が好きですが、もっと勉強したいです。（我喜欢日语，而且想再多学一些。）


小川：国文は　簡単ですが、数学は　少し　難しいです。
【语法精讲2】

が的其他用法！

【が】是日语中非常重要的助词之一，还可以用来提示句子主语


提示主语

表示动作或状态的主体。

例：彼が来ました。（他来了。）


*与【は】的区别

①【は】用于提出一个话题（主题），后续内容围绕这个主题展开。主语可能是已知信息，或需要与上下文形成对比。

例：私は学生です。（我是学生。→ 自我介绍，主题是“我”）


②【が】直接标示动作或状态的主体（主语），强调主语本身或新信息。

例：窓が開いています。（窗户开着。→ 强调“窗户”是开着的）


③疑问句回答时用【は】；疑问词（誰、どこ等）后用【が】

例：誰が来ましたか？→ 田中さんが来ました。（谁来了？→ 田中来了。→ 回答疑问词时用が）
