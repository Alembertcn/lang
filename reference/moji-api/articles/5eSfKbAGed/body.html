【语法精讲1】

表示列举多个动作

句式表达

〇〇（动词た形）たり〇〇（动词た形）たりする


句式讲解

1.用于用于列举两个或以上的动作；表示“有时……有时……”或“又……又……”。暗含还有其他动作的意思。

例：日曜日は　本を　読んだり、音楽を　聞いたり　しています。（周日有时读读书，有时听听音乐。）


2.若前后两个动词为相反动作时，则表示动作反复进行。

例：あの人は　立ったり　座ったりして、怪しいです。（那个人一会儿站一会儿坐的，真古怪。→又坐下又站起来又坐下，动作反复）

句式表达

例句

【语法精讲2】

【では】的用法

句式表达

名词 + では：表示 在某个范围、条件、场所、时间 内，后项的叙述成立。

*动词、形容词要变成名词形式才能接（比如：〜することでは、〜なのでは）


句式讲解

1.可表示地点/时间/条件范围：在东京、在日本、在学校里……

例句：この学校では英語だけでなく、中国語も学べます。（在这所学校，不仅可以学英语，还可以学中文。）


2.还可以表示比较/对比/强调：至于〇〇的话，情况是这样。

例句：日本では寿司が有名ですが、中国では餃子が有名です。（在日本，寿司有名；而在中国，饺子有名。）


小拓展：【では】vs 【には】

1.【では】强调“限定范围”：東京では寿司が有名です。（在东京，寿司很有名。→范围限定）

2.【には】着重 “在某范围内，存在/需要某事物” ：東京には有名な寿司屋があります。（东京有有名的寿司店。→强调存在/对象）

【语法精讲1】

表示假设的说法

句式表达

1.动词た形+ら：行く → 行ったら→否定：行かなかったら

2.形容词过去式+ら：高い → 高かったら→否定：高くなかったら

3.形容动词/名词+だったら：

静かだ → 静かだったら→否定：静かではなかったら/静かじゃなかったら

学生だ → 学生だったら→否定：学生ではなかったら/学生じゃなかったら


句式讲解

①表示假设条件，后项是基于该条件的结果。“如果……就”（通常表示特定的、一次性的假设）

例：あした雨が降ったら、試合は中止します。（要是明天下雨，比赛就取消。）


②表示真实条件，先后顺序，“一……就”

例：ドアを開けたら、猫がいました。（一开门，就有只猫。）


③表示建议/推测/逆接：偶尔强调结果出人意料

例：暇だったら、映画を見に行きませんか。（如果有空，要不要去看电影？）

良かったら、私の家に　来て、一緒に　お正月を　 過ごしましょうか。

【たら】【なら】表示的假设不同


【なら】的接续

动词/名词/形容词/形容动词原形+【なら】


【たら】vs【なら】

1.【たら】：强调动作先后顺序，可能包含逆接或意料之外的结果

【语法精讲2】

【楽しみ】VS【楽しい】

【楽しみ】：名词、形容动词

①指事物本身带来的愉快感：私はその本を楽しんで読んだ。（我津津有味地读完了那本书。）


②表示对未来某事的期待：明日の旅行が楽しみです。（很期待明天的旅行。）


【楽しい】：形容词

感受愉快、高兴的状态：子供たちと遊ぶのは楽しいです。（和孩子们玩很开心。）


【楽しみ】VS【楽しい】

【楽しみ】： 着眼于未来，表示期待

例：来週の旅行が楽しみです。（很期待下周的旅行。）

【楽しい】：着眼于现在或过去体验的感受

例：昨日のパーティーは楽しかったです。（昨天的派对很开心。）
