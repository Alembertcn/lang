#03 账号注册流程


1.打开报名官网，在页面左侧找到【注册个人信息】按钮，点击即可跳转至注册页面。


2. 进入【报考提示】页面后，仔细阅读并勾选同意相关条款，点击下一步继续。


3.根据实际情况填写个人资料与报考意向，设置好登录密码后提交，随后在弹出的确认窗口中核对信息。


4. 最()后()再次核对确认，确认无误后提交；若发现填写有误，可随时返回上一步修改。


  • 注意：
  1. 大陆地区考生请务必使用【有效期内的居民身份证】进行注册，并确保证件号码输入准确无误。
  2. 如果没有固定电话，联系电话一栏可填写【区号+手机号码】，此项虽不影响报名结果但为必填项。
  3. 在选择考试意向时，请认真确定自己要报考的级别；另外，预选的意向考点城市不会限制后续实际选择其他城市考点。


5. 注册完成后回到首页，登录报名系统，按照页面要求上传本人电子证件照，即可完成全部注册流程。


  • 注意：所上传的照片须为考生近6个月内拍摄的正面免冠彩色证件照（蓝底、红底、白底均可），文件大小控制在20kb至200kb之间，分辨率不低于360×480像素，格式仅限JPG。


#04 报名操作流程

报名流程参考往年报考经验，真实情况以官网正式报名流程为准


1. 打开报名官网，左侧登录报名系统。


2. 选定自己打算报考的级别。


3. 在()【选择考点】页面，先输入验证码，再挑选考点并预定考位。


4. 考位预定成功后，请在24小时之内完成【填写报名表并缴纳费用】。


#05 注意事项


♦ 报名系统不会保留往年的注册数据（往年注册过的同学们一定要注意！），打算参加12月考试的同学，请务必提前完成个人信息注册，千万别等到抢座当天才手忙脚乱。

♦ 设置注册密码时不必过于复杂，但一定要自己记清楚！否则临到报名时还要花时间找回密码，得不偿失。

♦ 报名过程中建议使用官方推荐的浏览器；如果家中网络不稳定，可以考虑前往网络条件较好的网吧操作。

♦ 同一账号仅支持在一台设备上登录，新设备登录后旧设备会被强制下线，不要尝试多人同时登录一个账号来抢座哦~

♦ 提前把自己心仪的考点位置记熟，抢座时就能快速定位！同时再准备两三个备选考点，万一目标考点已满，立刻切换不要犹豫。

♦ 如果遇到页面报错或验证码加载不出来，不要慌张，刷新一下页面通常就能解决。

♦ 预定考位后请尽快填写报名表并完成缴费，否则你抢到的考位会在24小时后被系统自动释放。

♦ 报名期间，官网每天早上7点会释放前一天未完成缴费的考位，没抢到的同学可以重点关注这个时段，捡漏成功率很高。

♦ 完成缴费后还有一次更换考点的机会，可以在第二天考位放出时尝试调整，即使没换成，原有的考位也会保留不受影响。


▷ 这些坑千万别踩！

  1. 时间：拖到最后一天才报名，可能遭遇服务器崩溃导致提交失败，通道关闭后不再补报；抢位当天如果没有卡点操作，热门考点很快就会被抢光。
  2. 照片：照片规格不符合要求会被系统反复驳回，白白耽误抢考位的黄金时间。
  3. 信息填报：姓名()、拼音()、证件号码等信息一旦提交缴费后就无法修改，若信息与证件不符将被禁止入场且不予退费。
  4. 缴费：预定考位后必须在24小时内完成缴费，超过时限系统会自动释放该考位。
  5. 渠道：只有教育部官方报名网站可以进行报名操作，轻信第三方代报服务可能面临个人信息泄露和额外加价的风险。
  6. 退改：缴费成功后原则上不支持退费以及更改级别，操作前请务必仔细确认。
  7. 设备：使用手机端或小众浏览器报名容易出现页面卡顿、闪退导致丢失考位，报名时优先使用电脑端的Chrome或Edge浏览器。


▷ 邪修抢座法

  1. 提前5-10分钟打开网站，提前3-5分钟完成登录，同时打开多个考点页面，哪个卡住就立刻切换到另一个页面继续刷新，互不耽误。
  2. 考点页面的第一个验证码直接跳过（出错率较高，免得浪费时间），提前将键盘切换到大写状态，开始抢座时立刻刷新验证码再输入，效率更高。
  3. 可以利用浏览器的记住密码功能，万一被卡住退出也能快速重新登录。
