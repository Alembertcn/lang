语法精析

～したほうがいい/～するほうがいい


释义

表示给予对方建议、劝告，不能用在自己身上。


接续规则

动词［原形・た形・ない形］＋ ほうがいい

形容词原形 ＋ ほうがいい

形容动词 + な + ほうがいい

名词 + の + ほうがいい


例句

1.体調が悪いなら休んだほうがいい。（身体不舒服的话休息一下比较好。）

2.明日は忙しいので、今日行くほうがいいです。（因为明天很忙，还是今天去比较好。）

【语法精讲2】

语法拓展

【～したほうがいい】VS【～するほうがいい】


【～したほうがいい】

1.表示说话人的个人推荐。

2.说话人的情感或个人意见较为明显，带有更强的个人色彩。

3.多用于具体或个别的情景，更倾向于个人经验或偏好的分享。

例：お腹が空いているなら、夜食を食べたほうがいいですよ。（如果你肚子饿了的话，建议你吃一点夜宵哦。）


【～するほうがいい】

1.表示客观建议。

2.说话人采取中立立场，不带有个人情感色彩。

3.通常用于一般性建议，不特定于某个具体情境。

例：あさ寒いから、暖かい服装をするほうがいい。（早上会有些冷，最好穿得暖和些。）
