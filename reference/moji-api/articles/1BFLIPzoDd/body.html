6.新しいSNSが若者の間で（ ）広まっている。
投票选项（最多1个）
1. どんどん
2. とうとう
3. どんなに
4. とたんに
正解：1 どんどん どんどん：表示事物进展迅速、接连不断。常与“広まる”“増える”等表示变化或扩散的动词搭配，意为“越来越……”“不断地……”。句中“新しいSNSが若者の間でどんどん広まっている”即“新的社交网站在年轻人中不断地普及开来”。 とうとう：意为“终于、最终”，多用于描述一个结果（往往是不好的或意料之中的），且常与过去时连用，如“とうとう終わった”。放在“広まっている”这种进行时中不自然。 どんなに：意为“多么……”，常与“ても”“でも”或感叹句呼应（如“どんなに楽しいか”），不能直接修饰“広まっている”。 とたんに：意为“刚一……就……”，前接动词た形（如“立ったとたんに”），表示两个动作几乎同时发生。后面不能接持续状态的“広まっている”。
