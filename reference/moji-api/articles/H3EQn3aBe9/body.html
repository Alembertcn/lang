引()言()

翻译完一篇文章，回看译文的时候，是否偶尔会发现自己的译文有些生硬，甚至会出现结构混乱等问题？ 翻译目的论打破了传统对“忠实原文”的局限，强调翻译的目标和功能才是决定译文成功与否的关键。这一理论赋予译者更大的自由度和创造性，相信能助你更灵活地应对不同的翻译任务，不会过于纠结逐字翻译。


翻译目的论


翻译目的论（スコポス理論）是由德国翻译学者汉斯·弗米尔提出的一个翻译理论，强调翻译的目的（スコポス）决定了翻译的策略和方法，要求翻译过程中应当关注文本所要达到的目的。

按照这一理论，译者应考虑不同场合下译文的具体目的和受众需求，确定翻译目的。译者的目的不同，译文的表达方式也会有差异。


目的论三原则


除了目的原则，目的论还包括连贯原则和忠实原则。连贯原则强调译文的可读性，忠实原则强调译文需忠实于原文。但在三原则中，目的原则处于首要的地位，是需要优先遵守的原则。


目的原则

试读结束仅对[全文付费]类型文章生效


翻译活动应该以翻译的目的为中心，翻译最终要满足目标语言读者的需求。因此需要根据不同()目的选择合适的翻译方法，而非拘泥于原文语言的束缚。


连贯原则


翻译要遵循连贯原则，以保证文章整体通顺。译文在目标语言中应该具有逻辑性和连贯性，使读者能够顺畅理解。连贯原则不仅要求段落内各句子之间的表达连贯，而且要注意段落之间的逻辑关系，确保译文的可读性和信息的接受度。


忠实原则


忠实性原则就是译文和源文本之间的连贯原则。尽管翻译应该以目的为中心，但同时也要尽可能忠实于原文的信息、意图和风格，完整及准确传达相关信息，根据具体情境选择直译、意译、增译、减译等策略，力求做到准确、翔实。


根据目的选择翻译策略


新闻 - 准确传达事实


新闻属于应用类文本，翻译目的是准确地传达原文的事实和信息。这一目的要求译文的用词需要严谨，翻译内容需要完整，确保信息的准确传达，不得随意增减信息。另外，不论是何种语言，新闻报道都需要保持客观性，语言需要中立客观，不能掺杂个人意见或情感，因此不能使用口语和主观性的表达。


例：

大学误操作致80人落榜？社媒网络炸锅了... 愛知医科大学 医学部入試で80人を誤って不合格に PC操作ミスで 愛知医科大学は、大学入学共通テスト


原文：愛知()医科()大学()は、大学()入学()共通()テストの結果()を利用()する医学()部()の入学()試験()で、本来()2次()試験()に進ん()でいた受験()生()80人()を誤っ()て不()合格()にしていたと発表()しました。


译文：爱知医科大学发布公告称，校方在根据大学入学共通测试成绩筛选考生的医学部升学考试中，误将本应晋级复试的80名考生判定为不合格。


文中“大学入学共通テスト”即“大学入学共通测试”，虽与中国的高考（普通高等学校招生全国统一考试）相似，但考试和录取制度上有所不同。比如共通测试的成绩只是大学录取的一个指标，考生还需要参加各大学的自主命题的考试，而中国高考的成绩、排名则是大多数高等院校在录取时主要、直接的参考依据。因此在讲究严谨、准确的新闻类文本中，不能简单翻译为“高考”，而应采取“直译+注释”的翻译策略，最大化保留其原本的意义。

而在其他一些类型的文本（如休闲类）中，由于目的不同，将「共通テスト」简单翻译为“高考”虽然会导致意义偏差，但却可以帮助读者快速理解其为何物。



休闲娱乐 - 轻松阅读


休闲娱乐类文本的翻译目的顾名思义，就是供读者休闲和娱乐，吸引读者，使读者能够轻松阅读。因此译文应该避免过于严肃，而是采用使用偏日常、生动的语言风格。此外，译文可以贴合网络热点，适当采用本土化的翻译，也可以适当玩梗，使其更贴近目标语言读者。


例：

七夕祈福卡TOP10 | 七夕短冊に書きたいことTOP10 ■圧倒的1位は「推しに会いたい」 昨年の同アンケート10位から大躍進、トップに躍り出ました♪コロナ禍


原文：ダイエット、リバウンド…と悩み()が尽き()ないZ世代()が多い()様子()。「痩せ()てから推し()に会い()たい」などと、原動()力()は人()それぞれ♡健康()な状態()を維持()することは何()より大切()に！自分()磨き()、みんなで頑張ろう()～♪


译文：许多 Z 世代的人们似乎苦恼于减肥后反弹，反弹后再减肥的经历。“想瘦下来见我推”……减肥的动力因人而异。保持健康的身体比什么都重要！大家一起努力，提升自己~♪


「推し」意为喜欢的人或者事物，在这里翻译成“偶像”也符合原文想要表达的意思。但是在如今的中国互联网中，越来越多人会直接使用“推”这个日文词汇来表达自己喜欢的偶像。虽然“推”在这里的用法不符合汉语的规范，但这个词如今已成为人人皆知的网络词汇。考虑到休闲娱乐类文本的翻译目的，在译文使用这些网络用词，更能使读者感到亲切，吸引阅读的兴趣。

此外，在新闻、学术类等较为严肃的文本中，词语和标点符号的使用都需严格遵守规范，但在休闲、娱乐的文本中并不需要太过严格，因此译文中保留了原文的波浪号和音符来凸显作者的感情。



学习备考 - 帮助学习者理解


学习备考类文本面向对题目有疑问的日语学习者或考生，翻译目的应是帮助其理解原文，因此译文应尽量忠实于原文，将原文的句子结构、词汇和语法原本的意思保留下来。同时也需要平衡句子的自然流畅，做到语言清晰易懂。


原文：映画()館()、平日()の昼()にしては、混ん()でたね。（2022年7月N2 听力问题4-3番）


原译：今天明明是工作日，而且还没到晚上，可电影院居然这么拥挤。


按学习备考目的修改：就工作日的白天来说，电影院里的人还挺多的。


在这一例子中，原译确实比直译更能表达说话者对“工作日里电影院人多”这一现象的意外，但是却没有将「にしては」原本的意义，即“按……说来”精确翻译出来，而是意译成了“明明”，可能会导致学习者（尤其是初学者）混淆「にしては」和「のに」的意义和用法。



会话 - 便于交流


会话类文本的翻译目的是便于交流。 因此需要使用口语化的语言，并考虑目标语言的文化习惯，调整表达方式，使译文更加贴近。此外口头交流都会使用较短的句子，因此翻译时应注意将结构复杂的长句子拆分成短句。


例：


原文：
A: 最近()どうですか？
B: 最近()は仕事()が忙しく()て、あまり自由()な時間()がありません。


原译：
A: 最近怎么样？
B: 最近工作很忙，没有多少自由时间。


修改：
A: 最近怎么样？
B: 哎，最近工作太忙了，几乎没什么时间休息。


原译中B的回答虽然保持了原文的意思，但在会话中显得比较生硬，过于书面化，不符合口语表达习惯，且缺乏日常会话中的语气。在中文环境中，这种回答会让听者觉得很奇怪。因此原译并没有达到“便于交流”的目的。在优化后的译文中，B的回答更符合日常口语的表达方式，添加了“哎”这样的语气词，使句子听起来更亲切、更符合日常对话的风格。


总结


无论是新闻、娱乐、会话还是其他类型的翻译，目的论都提供了一种全新的视角，引导译者根据具体语境和读者需求确定翻译目的，量身定制译文。在翻译之前，不妨先完整阅读一下原文，试着确定目的，然后带着这一目的去选择翻译策略。
