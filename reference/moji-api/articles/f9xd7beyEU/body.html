问题六【句子语法】


花山市では、きゅうりやトマト、なす（　　）夏の野菜が多く生産されている。
投票选项（最多1个）
とする
に関する
といった
に沿った
答案：3 「といった」 接续：名词 + といった + 名词 意思：“……等、像……这样的” —— 用于部分列举，暗示还有其他同类事物。 本句：「きゅうりやトマト、なすといった夏の野菜」 = “黄瓜、番茄、茄子等夏季蔬菜” 整体句意：在花山市，黄瓜、番茄、茄子等夏季蔬菜被大量生产。 其他选项为什么不对 1. とする 「AをBとする」=“把A当作B” / “视为”。 如果套入：「なすとする夏の野菜」→“把茄子当作夏季蔬菜” → 语法和意思都不通，因为前面列举了三样东西，不是在做定义。 另外「とする」前面常接「を」，这里没有。 2. に関する 「Aに関するB」=“与A相关的B”。 「なすに関する夏の野菜」→“与茄子相关的夏季蔬菜” → 意思是“关于茄子的夏季蔬菜”，逻辑奇怪，也不是在单纯列举。 4. に沿った 「Aに沿ったB」=“沿着A的B” / “按照A的B”（用于路线、方针、计划等）。 「なすに沿った夏の野菜」→“沿着茄子的夏季蔬菜” → 完全不通。
投票


问题七【句子语法】


この小説は、物語が進む（  ）主人公の少年の心理が変化していくのが面白い。
投票选项（最多1个）
としても
とはいえ
につれて
にあたって
答案：3 这个小说，随着故事的进展少年主人公的心理会发生变化这点很有趣。 1．としても：就算作为...也...作为，逆接用法，前项为确定或假定条件，与题意不符 2．とはいえ：虽说...但是...前接表示事实，或者说话人认为是事实的句子。后续句子并非表示单纯的事实，而是说话人做出的与「とはいえ」的前接内容意思相反的评价。与题意不符 3．につれて：随着 4．にあたって：表示在某个重要的时刻“值此……之际”“在……时候”
