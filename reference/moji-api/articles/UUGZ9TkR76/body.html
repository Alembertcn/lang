技巧解析

①适当加译，完整句意

加译-10人前ぐらいと推測し：【10人前ぐらいと推測し】没有出现指代词，但为了清晰“10人份左右”的所属出处，使译文更流畅、符合母语者使用习惯，此处译者加译了指代词【该食谱】

  

②看上下文，补足细节

意译-明治からは：本句为日语典型的省略句，可还原为【（大正時代のレシピは）明治時代から（のレシピより）は進歩した】。【から】表时间顺序，【は】强调对比，强调明治时代作为基准点，与大正时代进行比较。“明治时代与其之后（から）的大正时代相比（は）”
