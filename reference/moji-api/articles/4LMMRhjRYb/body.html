// 練習

日本語学校に通っているマリアさんは、学校が休みの日に日本の文化を習いたいと思っています。学校は土曜日と日曜日が休みです。少しでも安いほうがいいです。どの教室がいちばんいいですか。
投票选项（最多1个）
1.いけ花
2.日本料理のマナー
3.着物の着付け
4.すし作り
正解：3 訳文：マリア在日语学校学习，她想利用学校休息日学习日本文化。星期六和星期天是学校休息日，她想选便宜一些的教室学习。下面哪个最适合她？ 解説： 根据表格里面的星期・时间这一栏可知，周末可以学习穿和服和做寿司，而学习穿和服是免费的，学习做寿司需要花费2000日元，所以最适合マリア的是学习穿和服。
投票
日本の大学で勉強しているアレンさんは、平日の夕方、大学の帰りに何か習いたいと思っています。大学の授業は平日5時までです。アレンさんの趣味は料理で、日本の料理を作れるようになりたいと思っています。どの教室がいちばんいいですか。
投票选项（最多1个）
1.いけ花
2.日本料理のマナー
3.すし作り
4.天ぷら作り
正解：4 訳文：アレン在日本的一所大学里学习。他希望能利用平时下午放学后的时间学点什么东西。大学课程下午五点结束。アレン的兴趣是做菜，他想要学习做日本菜。下面哪个最适合他？ 解説： 根据表格可知，与做菜相关的有学习做寿司和炸鱼肉天妇罗，而学习做寿司是在星期天，学习炸鱼肉天妇罗在星期一和星期二的晚上，所以最适合アレン的是学习炸鱼肉天妇罗。
投票
