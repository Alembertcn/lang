【语法精讲1】

句式表达

动词原形 / 名词 + の + 前に (在……之前)


句式讲解

这个句型用于表示时间上的先后顺序，即后项的动作或事件发生在前项动作/事件完成之前。

1.【动词原形 + 前に】：表示在该动作尚未发生或完成的阶段。这里必须使用动词原形（基本形），而非“た形”。

2.【名词 + の + 前に】：表示在某个时间点或事件之前。


例句

1.日本に来る前に、少し日本語を勉強しました。(来日本之前，我学了一点日语。)

2.食事の前に、「いただきます」と言います。(在吃饭前，会说“我开动了”。)


小知识

反义表达【後に／後で】：表示“在……之后”

动词た形 + 後で

例：食事をした後で、散歩します。（吃完饭之后去散步。）

【语法精讲2】

句式表达

动词原形 / 动词ない形 + ようにする (争取做到……；设法使……；养成……的习惯）


句式讲解

1.【动词原形 + ようにする】：表示努力去做某事，使之成为习惯或状态。

例：毎日運動するようにする。（争取做到每天运动。）

2.【动词ない形 + ようにする】：表示努力避免某事，使之不发生。

例：遅刻しないようにする。（争取做到不迟到。）


【ようにする】 vs 【ことにする】

1.～ようにする→持续性的努力或习惯

毎日7時に起きるようにする。（努力做到每天7点起床。）→这是一个需要坚持的目标

2.～ことにする→一次性的决定或选择

明日から7時に起きることにする。（我决定从明天开始7点起床。）→决定第二天做什么事，一次性决定
