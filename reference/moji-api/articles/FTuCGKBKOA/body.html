以上就是今天的题目啦，下面是解析部分，来看看自己的答题情况吧~


第一题解析


1.おとなしい


正解()：3.たなかさんのいぬはおとなしいですね。


译文：田中的狗很温顺呢。


核心考点：本题考查形容词「おとなしい」的词义和使用对象。

「おとなしい」表示“老实的、安静()的()、温顺的”，通常用于形容人的性格、孩子或动物的性情，表示不吵闹、不调皮、性格比较温和。


选项分析

1.今週()はしごとのよていがおとなしいです。

译文：这周的工作安排很“温顺”。

「おとなしい」不能用来形容「予定()（よてい）」。

如果想表达“这周工作安排比较少 / 不太忙”，可以说：

今週()は仕事()の予定()が少ない()です。

→ 这周的工作安排比较少。

或者：

今週()はあまり忙しく()ないです。

→ 这周不太忙。

因此本项不自然。


2.きのうはおとなしい天気()でした。

译文：昨天是“温顺的”天气。

「おとなしい」一般不用于形容天气。

如果想表达“天气平稳、温和”，常用：

穏やか()な天気()

→ 温和()、平稳的天气

例如：

昨日()は穏やか()な天気()でした。

→ 昨天天气很平稳。

因此本项不自然。


3.たなかさんのいぬはおとなしいですね。

译文：田中的狗很温顺呢。

「おとなしい」可以用来形容动物性情温顺、不乱()叫()、不乱动，因此本项符合题意。

例句：

この犬()はとてもおとなしいです。

→ 这只狗非常温顺。


4.ここはとてもおとなしいレストランですね。

译文：这里是一家很“温顺”的餐厅呢。

「おとなしい」通常不能直接表示餐厅环境安静。

如果想表达“这家餐厅很安静”，应该使用：

静か()なレストラン

→ 安静的餐厅

例如：

ここはとても静か()なレストランですね。

译文：这里是一家很安静的餐厅呢。


第二题解析


2.田中「山川()さん、今日()の夕食()は何()にするんですか。」

山川()「これから買い物()に行っ()てカレーを（　）と思い()ます。」


正解()：1.作ろう()


译文：

田中：“山川，今天晚饭准备吃什么？”

山川：“我打算接下来去买东西，然后做咖喱。”


核心考点：本题考查「意向()形()＋と思う()」表示说话人的打算、意志()。

「V意向()形()＋と思う()」表示“我想…… / 我打算……”，用于表达说话人准备做某件事情的意志。


选项分析

1.作ろう()

「作ろう()」是()「作る()」的()意向()形()。

「意向()形()＋と思う()」表示说话人自己的打算或意志。

本题中：

カレーを作ろう()と思い()ます。

→ 我打算做咖喱。

与()前面()的()「これから買い物()に行っ()て」也能自然连接，表示“接下来去买东西，然后打算做咖喱”。

因此本项正确。


例句：

週末()は家()でゆっくり休もう()と思い()ます。

译文：周末我打算在家好好休息。


2.作り()ます

「作り()ます」是()「作る()」的()ます形()，表示()“做()、制作”。

但()是()不能()说()：作り()ますと思い()ます

如果()前面()使用()普通()形()，可()以说()：作る()と思い()ます。

不过「作る()と思い()ます」通常更接近“我认为（某人）会做”，重点是判断，而本题是在表达说话人自己的“打算”。

因此应使用：

作ろう()と思い()ます。


3.作っ()ています

「作っ()ています」表示“正在做”或某种持续状态。

例如：

今()、夕食()を作っ()ています。

→ 现在正在做晚饭。

但本题有「これから」，表示“接下来、从现在开始”，说明做咖喱这件事情还没有开始，因此不能使用表示正在进行的「作っ()ています」。


4.作っ()た

「作っ()た」是()「作る()」的()た形()，表示()“做了()”。

例如：

昨日()、カレーを作り()ました。

→ 昨天做了咖喱。

而题目中的「これから」表示接下来要做的事情，与表示过去动作的「作っ()た」不()符()。

因此本项不正确。


💡高频语法归纳

①「意向()形()＋と思う()」：打算……；想要……

接续：

动词()意向()形()＋と思う()


表示说话人在说话时产生或持有的意志、打算()。


例如：

日本()へ旅行()に行こう()と思い()ます。

我打算去日本旅行。


今日()は早く()寝よう()と思い()ます。

译文：今天我打算早点睡。


② 动词意向形怎么变？

一()类动()词()：词尾()う段() → お段()＋う

書く() → 書こう()

飲む() → 飲もう()

作る() → 作ろう()

行く() → 行こう()

二类动词：去掉「る」＋よう

食べる() → 食べよう()

見る() → 見よう()

起きる() → 起きよう()

三类动词：

する → しよう

来る() → 来よう()（こよう）

📌 意向形本身也可以表示“来……吧 / 我要……”这样的意志或提议。

例如：

一緒()に帰ろう()。

→ 一起回去吧。


③「～ようと思う()」vs「～つもりだ」

两者都可以表示“打算……”，但语感稍有不同。


～ようと思う()

表示说话人“想这么做、打算这么做”，常用于表达当前的想法或决定。

例：

今日()は早く()寝よう()と思い()ます。

→ 我今天打算早点睡。


～つもりだ

表示已经有比较明确的计划或打算。

例：

来年()、日本()へ留学()するつもりです。

→ 我打算明年去日本留学。


本题是山川在回答“今天晚饭准备吃什么”，表达的是自己接下来的打算，所以使用：

カレーを作ろう()と思い()ます。
