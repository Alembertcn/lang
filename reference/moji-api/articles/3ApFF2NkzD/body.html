真题：2015年7月N3 問題6

　学生のころ、私はよく近所の図書館を利用していた。飲食が禁止され、おしゃべりもできない図書館は、緊張感があったが、気持ちが落ち着く場所だった。静かな環境の中でゆっくりと本を読んだり、調べ物をしたりすることができた。

学生时期，我经常去附近的图书馆。虽然不能饮食，又不能讲话的图书馆有一种紧张感，但这个地方却能让人平心静气，能够在安静的环境中悠闲地读读书或者查查资料。
[ 点击显示译文 ]


　働き始めてからは図書館に行く機会はなかったが、先週近くを通ったので、久しぶりに寄ってみた。すると、そこは全く違う場所になっていた。

开始工作之后，我一直没有机会去图书馆，上周经过附近，所以久违地顺道去了。进去之后，我发现那里变成了完全不同的地方。
[ 点击显示译文 ]


　まず気づいたのは、音だ。音楽が流れているし、おしゃべりをしている人もいる。そして、館内にカフェもできていて、コーヒーを飲みながら本を読んでいる人もいる。本当に驚いてしまった。

首先注意到的是声音。那里播放着音乐，还有人在说话。图书馆内还开了一家咖啡馆，也有人一边喝咖啡一边读书。我感到很惊讶。
[ 点击显示译文 ]


　本を借りるとき、係り人に「久しぶりに来たら、ずいぶん変わっていて、びっくりしてしまいました」と言うと、「そうなんですよ。ふだんあまり本を読まない人たちにも来てほしいということで、こんな感じに変えることになったんです。それに、閉館時間を遅くしたので、仕事の帰りに来る方も増えたんですよ。」と話してくれた。

借书的时候，我对工作人员说：“我好久没来了，这里变化好大啊，吓了我一跳”，他告诉我：“是呀。为了让平时不怎么读书的人也来，就弄成这样子了。而且闭馆时间也延后了，所以下班回家的途中来这里的人也增多了”。
[ 点击显示译文 ]


　確かに、みんな楽しそうに時間を過ごしていた。こういう図書館なら、それほど本が好きではない人も来やすくなって、本に興味を持つ人も増えていくだろう。だが、図書館全体に流れていた、あの落ち着いた静かな空気はなくなってしまった。この図書館にも静かに本を読みたい人のための部屋が用意されているそうだが、私は、やはり図書館と言う場所は、静かで落ち着いた場所であってほしいと思うのだ。

的确，大家在图书馆的这段时间，看上去都很开心。即使是不太喜欢书的人，来到这样的图书馆也可以放轻松，这样一来，对书感兴趣的人也会变多吧。但是，过去弥漫在整个图书馆的那种平静和安宁的气氛已经一去不复返了。虽然图书馆里也给想要安静读书的人准备了房间，但我还是希望图书馆这种地方是一个安静的，能够让人平静下来的地方。

//練習

34. 本当に驚いてしまったとあるが、例えばどんなことに驚いたのか。
投票选项（最多1个）
1.図書館が前とは違う場所に建てられていたこと
2.図書館の中に音楽が流れていたこと
3.図書館の中で誰もおしゃべりをしていないこと
4.図書館がカフェに変わっていたこと
正解：2 訳文： 1.图书馆建在了与之前不同的地方 2.图书馆内播放着音乐 3.图书馆内没有人聊天 4.图书馆变成了咖啡馆 解説： 文中明确提到「音楽流れているし、おしゃべりをしている人もいる」（播放着音乐，也有人聊天），以及「館内にカフェもできていて」（馆内还开设了咖啡馆）。但最直接的惊讶点是音乐播放（选项2），因为这与传统图书馆的安静形象形成强烈对比。
投票
35. 図書館の人によると、この図書館はどのような考えで変えられたのか。
投票选项（最多1个）
1.図書館の中にカフェを作って、図書館の収入を増やしたい。
2.図書館全体を落ち着いた静かな環境にして、利用者を増やしたい。
3.図書館の閉館時間を変えて、早朝しか来られない人にも来てもらいたい。
4.図書館をもっと身近な場所にして、今まで来なかった人にも来てもらいたい。
正解：4 訳文： 1.在图书馆内开设咖啡馆以增加收入 2.将整个图书馆变成安静的环境来增加使用者 3.改变闭馆时间让只有早晨能来的人也能使用 4.让图书馆变得更亲近，吸引之前不来的人 解説： 工作人员说明「ふだんあまり本を読まない人たちにも来てほしいということで」（为了让平时不怎么读书的人也能来），核心目的是扩大用户群体（选项4）。虽然提到延长开放时间（选项3部分正确），但这是手段而非根本目的。
投票
36. 「私」は、前の図書館と今の図書館を比べてどう思っているか。
投票选项（最多1个）
1.今の図書館より、前の図書館のほうが好きだ。
2.前の図書館より、今の図書館のほうがすきだ。
3.前の図書館も今の図書館も同じくらい好きだ。
4.前の図書館も今の図書館もあまり好きではない。
正解：1 訳文： 1.比起现在的图书馆更喜欢以前的 2.比起以前的图书馆更喜欢现在的 3.以前和现在的图书馆都喜欢 4.以前和现在的图书馆都不太喜欢 解説： 作者最后明确表达「やはり図書館と言う場所は、静かで落ち着いた場所であってほしい」（还是希望图书馆是安静沉稳的场所），且怀念「あの落ち着いた静かな空気」（那种沉稳安静的氛围），说明偏好旧馆（选项1）。
投票
37. 「私」は、どのような図書館がよいと言っているか。
投票选项（最多1个）
1.緊張感があり、すいている図書館。
2.図書館全体が静かで落ち着いた感じの図書館。
3.音楽が流れ、自由におしゃべりできる図書館。
4.静かにする場所とそれ以外の場所が分かれている図書館。
正解：2 訳文： 1.有紧张感且人少的图书馆 2.整体安静沉稳的图书馆 3.播放音乐可以自由聊天的图书馆 4.安静区域与其他区域分开的图书馆 解説： 作者理想中的图书馆是「静かで落ち着いた場所」（安静沉稳的地方），且全文未提分区需求（选项4错误）。虽然新馆设有静音室，但作者期待的是整体氛围（选项2），而非局部解决方案。
投票

1.〜そうだ

接続

動詞普通形 + そうだ

意味

表示听说或传闻

例文

①この図書()館()にも静か()に本()を読み()たい人()のための部屋()が用意()されているそうだ。/听说这个图书馆也为想安静读书的人准备了房间。

②あのレストランはとてもおいしいそうだ。/听说那家餐厅很好吃。
