【语法精讲1】

什么？形容词还分两种？

形容词（い形容词）：常以【い】结尾，可以直接接名词

1.これは　田中さんの　広いアパートです。（这是田中宽敞的公寓。）

2.素晴らしい歌。（极棒的歌曲。）

3.安いギター。（便宜的吉他。）


形容动词（な形容词）：形似名词，但并非名词；接名词时需要+【な】

1.これは　中井さんの　綺麗な絵です。（这是中井的佳画。）

2.好きなこと。（喜欢的事。）

3.すてきな女性。（优秀的女性。）

【语法精讲1】

句尾加个“わ”也能加强语气？

句式表达

形容词 + わ：寒いわ

形容动词／名词：+ ですわ：便利ですわ、学生ですわ

动词原形 + わ：行くわ


句式讲解

①常见于女性口语；表达感叹、强调、情绪色彩。类似中文里的“啊”“呢”“呀”。

例：すてきですわ。（真好啊。）

②断定／强调；说话者带有坚定的态度，但语气依旧柔和。比【よ】要温和一些。

例：明日行くわ。（我明天会去的。）

③在现代年轻人口语中用得少；多见于 年长女性 或 漫画、小说中的女性角色。

在关西方言中，男性也会用【やわ】表示感叹（比如大阪腔）。

例：めっちゃおいしいわ。（真好吃啊。）


小拓展

【ですわ】更上品、礼貌，常见于大小姐/优雅女性的口吻。

すてきですわ、お客さん。……じゃ、これに　します。
【语法精讲2】

“你要什么〇〇？”“我要〇〇”

句式表达

〇〇は　何に　しますか。（你想要什么？）

〇〇に　します（我要……）


句式讲解

1.〇〇は　何に　しますか

①【〇〇は】：提示提问的对象，通常为人物

②【に】表示选择的对象。


2.〇〇に　します

【〇〇に】：提示选择的对象，通常为名词


例句

1.飲み物は　何に　しますか。（你要什么饮品呢？）

-紅茶に　します。（我要红茶）


2.食べ物は　何に　しますか。（你要什么食物呢？）

-すしに　します。（我要寿司。）
