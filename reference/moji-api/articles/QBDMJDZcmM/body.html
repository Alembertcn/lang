技巧解析

词汇优化，突出特色

润色-古い：本意为【以往；古老，陈旧】等，此处与【记忆】搭配，可选用【遥远的】等词，更加符合中文表达习惯。

调整语序-たから：原句中表现因果关系的词出现在句末，翻译时可将其提前，并使用【之所以……是因为】句式，可使句子表意更流畅，且符合中文表达习惯。

上下语境

意群1：目を輝かせ、地図への熱い思いを語る田中さん

直译：目光炯炯地讲述自己对地图的热爱的田中先生


意群2：田中さんの言葉を聞きながら

组装信息

意群顺序梳理：

意群1为前段内容“田中述说”的总结，意群2叙述视角由田中转移到了笔者，进而引出意群3笔者的联想，因此顺译即可。即【意群1→意群2→意群3】


全句粗译：目光炯炯地讲述自己对地图的热爱的田中先生。笔者听着他的话，感觉小学时期的自己好像也在跟着富永一起点头。

【进阶精译】

技巧解析

①词汇优化，突出特点

润色-目を輝かせ：可直译为“眼睛亮起来”，是很有画面感的词汇。此处可选用“目若悬珠”，该词意为“形容眼睛明亮，有光彩”，因此译文文学化再造，提升文本质感。


②调整语序，转换表达

倒译-田中さん：观察句子结构可知，下划线部分都是修饰“田中先生”的长定语。遇到这类句子，将其中心语提到句首译出，再将长定语译出即可，即将名词句改写成动词句。


③切分句子，清晰易懂

分译-田中さんの言葉を聞きながら：此处可以适切分成两个小句，即【田中さんの言葉/私は田中さんの言葉を聞きながら】，“田中先生说的话”“我听他说话，不由得……”且用代词“他”指代田中，这样表意更为清晰，可读性也更强。


得出精译：田中先生目如悬珠般诉说着自己对地图的热爱。笔者听着他的话语之余，感觉小学时期的自己好像也在跟富永一起点头频频。
