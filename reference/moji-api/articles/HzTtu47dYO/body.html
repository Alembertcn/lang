释义

1.动词原型/形容词 + し

注意

与【上に】的区别：只做并列列举，不强调递进，语气平淡；暗示除了列举出来的之外，还有其他情况

うちに


释义1

在……期间；趁着……

表示某状态还在持续期间进行某事，适合用于计划、动作、劝告类语境


接续规则

动词原形/形容词/+うちに

名词+の+うちに

形容动词+な+うちに


例句

1.忘れないうちにメモしておこう。（趁还没忘记，赶快记下来吧。）

2.若いうちにたくさん旅行したほうがいい。（趁年轻多去旅行比较好。）

注意

常与【まだ、早い、若い、覚えている、忘れない 】等状态/心理动词搭配使用
