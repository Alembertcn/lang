语法精讲

～たり～たりする


释义

表示列举、举例不同的动作或情况


接续规则

1.动词た形+り

例：食べる → 食べた → 食べたり

2.い形容词（去い）+ かったり

例：寒い → 寒かった → 寒かったり

3.な形容词 + だったり

例：元気→ 元気だった → 元気だったり

4.名词 + だったり

例：先生 → 先生だった → 先生だったり


例句

宿題をしたり、手紙を書いたり、今日はとても忙しかった。（又做作业又写信的，我今天特别忙。）

一人で本屋に行ったり、花屋に行ったりしました。

语法拓展

～たり～たりする的拓展释义


1.表示变化，不同情况反复变化。

例句：最近の天気は暑かったり、寒かったりします。（最近的天气冷热无常。）


2.表示反复，反复出现相反或相对的动作或状态。

例句：あの人は門の前を行ったり来たりしています。（那个人在门前走来走去的。）


注意点

1.不能用于只发生一次的动作。

例句：昨日は映画を見たりしました。×（昨天下午只看了电影，不能用「たり」）

2. 一般不用于正式书面表达，更适合口语和日常交流。

如果要正式书写，通常会改为「～や～など」或其他更正式的表达。

语法精讲

～ながら～


释义

表示同一主体同时进行两件事


接续规则

1.动词ます形去ます + ながら

如：食べる→ 食べながら

！不可接续名词、形容词


例句

【语法精讲2】

语法拓展

该语法的注意点

1.主语必须相同

正确例句：私は歌を歌いながらピアノを弾きます。（我一边唱歌一边弹钢琴。）

错误例句：彼は歌を歌いながら、私はピアノを弾きます。（主语不同，不能用【ながら】）


2.主次关系

ながら前面的动作为次要，后面的动作为主要。

例句：歩きながら考えます。（边走路边思考。） → 主要是思考。
