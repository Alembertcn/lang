【语法精讲1】

ついでに


释义

“顺便、借……的机会”

表示在进行某项主要行动的过程中，顺便进行另一项相关或不相关的动作。后一动作常为偶然顺带进行的。


接续规则

1.动词ます形（去掉ます）/动词た形+ついでに

2.名词+の+ついでに


例句

1.薬局へ行ったついでに、トイレットペーパーも買いました。（趁去药店的工夫，我还顺便买了卷卫生纸。）

2.コンビニに行くなら、ついでにお酒も買ってきてくれない？（你要是去便利店，能不能顺手帮我带瓶酒回来？）

「張さん、こんにちは。その方はお母さんですか？」と聞くと、張さんは少しはずかしそうに「はい、母です。今日は学校を見に来たついでに、桜も見に来ました」と言いました。
【语法精讲2】

そうに/そうな


释义

表示说话人根据对方的外观、表情、动作等客观信息，对其情绪或状态进行推测，常译为“看上去……”“显得……”等。

不能用于说话人自己的情绪或状态


接续规则

1.动词ます形（去掉ます）+そうに+动词

2.形容词词干（去い）+そうに+动词


例句

1.彼は忙しそうに仕事をしている。（正在工作的他好像忙得不可开交。）

2.つまらなそうなパーティーには行きません。（看起来很无聊的派对我才不要去。）


注意

【そうな】【そうだ】用法相同，但【そうだ】用于句子结尾，【そうな】后只能接名词


【そうに】VS【ように】

释义不同

1.【そうに】表达主观判断、猜测，不可用于表达比喻

2.【ように】表达比喻/“按……方式”/表示目的或结果


接续不同

1..动词ます形（去掉ます）/形容词词干（形容词去い）+そうに+动词

2.名词+ のように / 动词原形 + ように


例句

1.他用一副要哭了的样子说话

泣くように話した。×

泣きそうに話した。√


2.像猫一样走路

猫そうに歩いた。×

猫のように歩いた。√
