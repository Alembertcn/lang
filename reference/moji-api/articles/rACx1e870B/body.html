【语法精讲1】

おそれがある


释义

“担心……/恐怕会……/有……的风险”

表示有发生某种不好的事情的可能性、危险性或担忧，常用于书面语、新闻、正式场合等。


接续规则

1.动词原型+ おそれがある

2.名词 + の + おそれがある


例句

1.台風の影響で、今夜は大雨になるおそれがある。（ 由于台风的影响，今晚恐怕会下大雨。）

2.今夜から明日にかけて、大雨のおそれがあります。（今晚到明天都有下大雨的可能）

午後のゼミでは経済学の発表がありました。この間ずっと準備していましたが、病気のせいで発表がなかなかうまくいきませんでした。途中で咳が出てしまい、思うように話せませんでした。授業が終わった後、先生に「そのまま無理をすると、肺炎になるおそれがある。今日はゆっくり休みなさい」と言われました。

【语法精讲1】

【気がつき】是【気がつく】的连用形


気がつく


释义

常用于形容想到了什么、灵感浮现的情况，以及注意到了某种细节时使用


常用搭配

1.気がつく + と “一回过神来就发现……”多用于出乎意料的变化

例：気がつくと、外は真っ暗だった。（回过神来，外面已经一片漆黑。）


2.気がつかないうちに “在不知不觉间……”

例：気がつかないうちに、彼女はいなくなっていた。（不知不觉中，她已经离开了。）


3.〜に気がつく “注意到……、意识到……”

例：間違いに気がついた。（注意到了错误）


例句

田中「今日は残業？」（田中：“你今天加班？”）

山田「うん。さっき資料を見直していたらミスに気がついて、急いで修正しているところだよ。」（山田：“嗯，刚刚检查资料的时候发现了错误，正在紧急修改”）

家に帰って布団に入りながら、自分が病気の体に無理をさせていたことに気がつきました。これからは体のサインをちゃんと見て、早めに対応しようと心に決めました。
【语法精讲2】

気をつける


释义

“留心、留意”。常用于避免出现错误或者不好的影响而需要留心、注意的情况


例句

山田「川本さん、資料のデータの日付が間違っていたよ。」（山田：“川本，资料里的数据日期搞错了哦，”）

川本「すみません。今後気をつけます。」（川本：“对不起以后我会注意的。”）


【気がつく】VS【気をつける】

1.【気がつく】：事后察觉；强调过去没有注意到，现在察觉了

2.【気をつける】：主动留意，强调防止发生问题


举例

忘れ物に【気がついた】……（事后发现忘了东西）忘れ物に【気をつける】…（要注意不要忘记东西）
