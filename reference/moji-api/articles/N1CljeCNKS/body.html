语法拓展

～ように（像……一样）


接续规则

动词原形／ない形＋ように

名词＋のように


【～とおりに】VS【～ように】

【～とおりに】

1.严格遵循前项内容（如规则、指示、事实），强调完全一致。

2.侧重“复制”或“重现”前项，不允许偏差。

例：マニュアルのとおりに操作する。（按照手册的指示进行操作。）→严格按照手册操作，步骤完全一致。


【～ように】

1.目标导向或比喻性模仿，侧重结果的相似性，不要求过程完全一致。

2.允许根据实际情况调整，甚至包含主观努力或愿望。

例：マニュアルのように操作する。（像手册那样操作像）→可能简化步骤，但结果相似。

语法拓展

～によっては


接续规则

名词+によっては

经常与人、场所、国家、日子、时间、状况、情况等搭配使用


【～によって】VS【～によっては】

～によって：更侧重于说明不同条件会导致不同结果，适用于描述普遍现象或一般规律。常与【異なる】【違う】等词搭配。

例： 天気によって服装が違う。（根据天气，服装会有所不同。）→这是一个普遍现象，说明天气条件不同，人们的服装选择也会不同。


～によっては：更侧重于强调在特定情况下可能出现的特殊情况，语气更强调例外或特定条件。

例：天気によっては、ピクニックを中止する。（如果天气不好，可能会取消野餐。）→这里强调了在特定的天气条件下（如雨天或恶劣天气），可能会出现取消野餐的特殊情况。
