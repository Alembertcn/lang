4.信号無視をした自転車が急に飛び出してきて、（ ）。
投票选项（最多1个）
1. ぶつかるところへ
2. ぶつかるところだった
3. ぶつかったところだ
4. ぶつかるところを
正确答案：2. ぶつかるところだった 中文翻译：无视信号灯的自行车突然冲出来，差点撞上。 语法接续与释义： - ～ところだった：表示“差点就……、险些……”。用于描述某种危险或不好的事情险些发生，但实际上并未发生。常与「もう少しで」「危うく」等副词呼应。 - 接续：动词原形 + ところだった。 各选项分析： 1. ぶつかるところへ：错误。「ところへ」表示“正当……的时候”，多用于某动作或状态发生时插入另一动作。本句并非插入，而是险些发生的结果，语义不符。 2. ぶつかるところだった：正确。表示“差点撞上”，符合前面自行车突然冲出的语境，且「ところだった」是表示险些发生的标准句型。 3. ぶつかったところだ：错误。「～たところだ」表示“刚刚做完……”，意为“刚撞上”。但实际并未撞上，且与“突然冲出来”的突发性不符。 4. ぶつかるところを：错误。「ところを」表示“正……的时候”，常用于被干扰或被动场景，如「見られているところを盗んだ」。本句不适用。

5.海外の大学に留学することが決まった以上、（ ）。
投票选项（最多1个）

正确答案：4. その国の言語と習慣を身につけなければならない 句子中文翻译： 既然决定了要去海外大学留学，就必须掌握那个国家的语言和习惯。 词汇解析： - ～以上（は）：接续助词 - 接续：动词/形容词连体形 + 以上（は） - 释义：既然……就……。表示从前项事实出发，得出后项必然的结论、义务或决心。 各选项分析： 1. 身につけてしまった ❌ - 过去时 + てしまう（完成/遗憾）。既然才刚刚决定留学，不可能已经掌握了语言和习惯。时态矛盾。 2. 身につけるらしい ❌ - 传闻或推测（“好像是会掌握”）。不构成“既然……就……”的逻辑关系，语气太弱，不合适。 3. 身につけるわけではない ❌ - “并不是要掌握”。与「～以上」的强逻辑推导相悖，如果并非必须掌握，那为什么说“既然决定留学”呢？意思矛盾。 4. 身につけなければならない ✅ - “必须掌握”。表示留学带来的义务或必要准备，符合「～以上」的用法，自然通顺。 因此选 4。
