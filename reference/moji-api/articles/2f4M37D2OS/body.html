【语法精讲1】

句式表达

动词原形／ない形 + と (一旦……就……；如果……就……)


句式讲解

这个句型用于表示确定条件，即只要前项发生，后项就必定、客观地随之发生。

后项多为自然现象、机械性反应、普遍真理或习惯性结果，通常不接主观意志、命令、劝诱等表达。


例句

1.春になると、花が咲きます。（一到春天，花就会开。）

2.このボタンを押すと、ドアが開きます。（一按这个按钮，门就会开。）

【语法精讲2】

句式表达

动词原形 + ことができます (能够做…… / 可以做……)


句式讲解

1.【动词原形】：表示想要表达“能够”或“可以”的具体动作内容。

2.【ことができます】：作为固定搭配，表示能力或可能性。相当于“能”、“会”、“可以”。


例句

1.私は日本語で話すことができます。(我能够用日语说话。)

2.この図書館では本を借りることができます。(在这个图书馆可以借书。)

【语法精讲1】

句式表达

〇〇て + あります (表示动作结果的状态 / ……着)


句式讲解

【他动词て形 + あります】：表示某人有意识地进行某个动作后，其结果作为一种状态持续存在。常用于描述为某种目的而事先做好准备的场景。主语通常是物。


例句

1.窓が開けてあります。（窗户开着。/ 有人打开了窗户，现在保持开着的状态。）

2.壁に地図が貼ってあります。(墙上贴着地图。/ 暗示是有人为了让大家看而贴的。)


与【ています】的辨析：

①自动词 + ています：表示自然的状态或现象持续。不强调人为动作。

例：窓が開いています。（窗户开着。/ 单纯描述窗户是开着的状态。）

②他动词 + ています：表示动作正在进行或习惯。

例：今、窓を開けています。（现在正在开窗户。）


〇〇てあります：强调人为动作后留下的状态，有时隐含“为某人而做”的目的性。

金額は　目的地の　下に　書いて　あります。目的地の　ボタンを　押せば、金額が　出ます。
【语法精讲2】

句式表达

ば形 (条件形 / 如果……)


句式讲解

【动词/形容词/名词的ば形】：构成一个条件从句，表示“如果……就……”。根据前接词的不同，变换规则和含义略有差异。

①一类动词 (五段动词)：将词尾变为相应的“え段假名” + ば：

例：行く → 行けば、話す → 話せば

②二类动词 (一段动词)：去掉词尾る + れば。

例：食べる → 食べれば、見る → 見れば

③三类动词 (カ变动词/サ变动词)：

来る → くれば

する → すれば

④い形容词：去掉词尾い + ければ：

例：高い → 高ければ、忙しい → 忙しければ

⑥な形容词 / 名词：词干 + であれば（口语中也常用 なら）

例：静か → 静かであれば、学生 → 学生であれば


例句

1.このボタンを押せば、ドアが開きます。(如果按这个按钮，门就会开。)

2.天気がよければ、ピクニックに行きます。(如果天气好，就去野餐。)
