【语法精讲1】

语法精析

动词意向形 + と思う


释义

表示说话者在说话时表达自己所考虑的计划或决心

1.【～ようと思う】表示当前或未来的打算、意图或决心。

例文：今から勉強しようと思う。（我打算现在学习。）

表示你目前有这个打算或想法。


2.【～ようと思いました】表示过去做出的打算或决定。

例文：昨日勉強しようと思いましたが、結局寝てしまいました。（昨天我打算学习，但最后睡着了。）

表示在过去你曾有过这个打算，但并没有实现。


意向型变形规则

一类动词（五段动词）：将词尾的【う】改为【おう】

例：行く（いく）→ 行こう（いこう）

二类动词（一段动词）：将词尾的【る】改为【よう】

例：食べる（たべる）→ 食べよう（たべよう）

サ变动词：する → しよう

来る：来る（くる）→ 来よう（こよう）

来週の日曜日、大学の友達と多摩川公園でピクニックをしようと思っています。
【语法精讲2】

语法拓展

与【～つもり】【～ことにする】【～たい】比较


1.【～ようと思う】表达正在考虑中的计划或想法，带有试探性或不确定性。

例：来週、日本へ旅行に行こうと思う。（我考虑下周去日本旅行。）


2.【～つもり】更侧重于实际的计划和准备比较正式，带有一定的确定性。

例：来週、日本へ旅行に行くつもりで、プランはもうしました。（我打算下周去日本旅行，已经做好了计划。）


3.【～たい】表示愿望，通常不包括“决心”或“计划

例：来週、日本へ旅行に行きたいです。（我想下周去日本旅行。）


4.【～ことにする】强调主动性，用于表达经过思考后做出的决定。

例：いろいろなことを考えて、日本へ進学することにしました。（经过多方面考虑，我决定去日本留学。）

【语法精讲1】

语法精析

あげる（普通）→さしあげる（尊敬）

主语是给予者


用法

1.单独使用【あげる】，意为“给予”

私は友達に本をあげる。（我给朋友书。）


2.【动词て形+あげる】，“为某人做某事”

私は友達に料理を作ってあげる。（我为朋友做饭。）


注意点

过度使用【あげる】并不礼貌，需要慎重使用。

タイ人の留学生ナタポンさんは「トムヤムクンを作ってあげます」と元気よく言いました。
【语法精讲2】

语法拓展

もらう（普通）→ いただく（尊敬）主语是接受者

1.单独使用【もらう】用于说话人或自己一方得到别人的东西或帮助。可使用助词【に】或【から】

例句：私は友達にプレゼントをもらう。（我从朋友那里收到礼物。）


2.【动词て形+もらう】表示“请别人为自己做某事”，强调自己的请求或接受行为。

例句：私は友達に料理を作ってもらう。（我请朋友为我做饭。）


3.【请求：てもらえませんか】“你能为我做某事吗？”，委婉语气

例句：この荷物を持ってもらえませんか？（你能帮我拿这个行李吗？）


くれる（普通）→ くださる（尊敬）主语是给予者

1.单独使用【くれる】，表示别人给自己东西或帮助

例句：友達は私にプレゼントをくれる。（朋友给我礼物。）


2.【动词て形+くれる】表示“别人为我做某事”，强调对方的主动行为。

例句：友達は私に料理を作ってくれる。（朋友为我做饭。）


3.【请求：てくれませんか】“你能为我做某事吗？”，语气委婉

例句：この荷物を持ってくれませんか？（你能帮我拿这个行李吗？）


4.【命令：てくれ】

例句：静かにしてくれ！（安静点！）
