【语法精讲1】

如何列举多个原因

句式表达

〇〇し、〇〇し…


句式讲解

1.动词/形容词原形 + し

2.形容动词/名词 +だ + し


例句

1.外は雨だし、寒いし、出かけたくない。（外面又下雨，又冷，不想出门。）

2.この店は安いし、味もいいし、人気があります。（这家店便宜、味道也好，很受欢迎。）


【~し~し】【から】【ので】的区别

【から】常用于主观原因：時間がないから、行けません。（因为没时间，所以去不了。）

【ので】常用于客观原因，更正式：雨が降っているので、出かけません。（因为下雨，所以不出门。）

外は　雨ですし、出かけたくないので、出前を　注文しようかなと　思っています。

句式讲解

1.接续规则：动词/名词/形容词/形容动词原形 + かな／かしら

2.通常用于表示疑问、半信半疑、自言自语，对某件事没有把握时使用；有时包含期待对方回应的意思。

【语法精讲1】

【中】的两种读法及用法

句式表达

名词（时间/带有动作性质的名词） + 中


句式讲解

1.【ちゅう】：接动词词干、动名词，表正在进行的，读作；属于书面语、正式表达，比【ている】更书面。

2.【じゅう】：表示范围、整个时间/空间；强调“从头到尾”“到处”。


例句

1.点検中（ちゅう）のため、このエレベーターは使えません。（因为正在检修，这部电梯不能使用。）

2.一日中（じゅう）雨が降っていました。（一整天都在下雨。）

雨の日に、一日中、配達の　人も　大変ですね。……もし時間が　かかっても、文句を　言わないでくださいね。
