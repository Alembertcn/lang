如何表达空间的“前”与“后”

句式表达

名词 + の + 前に / 後ろに（在……的前方/在……的后方）


句式讲解

1.当表示空间位置时，必须通过【名词+の】来指定“什么”前面或后面。

2.【前に/後ろに】后接的名词，才是叙述的主体。

“哪里有什么”的表达方式

句式表达
