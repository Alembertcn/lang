问题一


1番
投票选项（最多1个）
1.夏用の商品を棚に並べる
2.倉庫に日焼け止めクリームを運ぶ
3.パンに値引きシールをはる
4.棚の商品を片付ける
正确答案：3.パンに値引きシールをはる(给面包贴上打折标签) 1.夏用の商品を棚に並べる(将夏季商品摆上货架) 2.倉庫に日焼け止めクリームを運ぶ(将防晒霜运送到仓库) 4.棚の商品を片付ける(整理货架上的商品)

问题二

1番
投票选项（最多1个）
1. 子供の年齢や好み合う絵本
2. 教育効果が高い絵本
3. 長い間読まれている名作の絵本
4. 自分自身が面白いと感じる絵本
